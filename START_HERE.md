# Start Here

## Goal

Build a public GitHub portfolio that documents the transition into Technical Program Management, R&D Delivery, Product Operations, and AI/ML Program Management.

Feintt.ai is the flagship applied case study.

## Step 1 - Create The GitHub Repository

Create a new public GitHub repository:

```text
hen-technical-pm-portfolio
```

Recommended description:

```text
Technical Program Management, Product Operations, R&D Delivery, and AI/ML Program Management portfolio built around Feintt.ai as a real software/data/AI case study.
```

## Step 2 - Push This Local Repository

After creating the GitHub repository, connect this local folder to the remote:

```bash
git remote add origin https://github.com/YOUR_USERNAME/hen-technical-pm-portfolio.git
git add .
git commit -m "Initial Technical PM portfolio"
git push -u origin main
```

## Step 3 - Enable GitHub Pages

In the GitHub repository:

1. Go to `Settings`.
2. Go to `Pages`.
3. Choose `Deploy from a branch`.
4. Branch: `main`.
5. Folder: `/docs`.

Your site should become available at:

```text
https://YOUR_USERNAME.github.io/hen-technical-pm-portfolio/
```

## Step 4 - Start The Courses

Do not treat the courses as certificates. Treat each one as material for this portfolio.

| Course | What To Build In This Repo |
|---|---|
| IBM IT Project Manager | SDLC notes, program charter, risk log, project status report |
| Software Product Management | Product requirements, user stories, backlog, release plan |
| IBM Product Owner selective modules | Backlog refinement, stakeholder plan, capstone artifact |
| Git / GitHub / terminal / Python / Docker basics | Technical setup notes and small demos |
| DataTalksClub LLM Zoomcamp | RAG, evals, monitoring, cost, and AI workflow case study |

## Step 5 - Weekly Rule

Every week must end with one visible update:

- New artifact
- Improved case study
- New dashboard spec
- New decision log entry
- New release readiness update
- New learning note linked to Feintt.ai

If the learning does not create evidence, it is not yet useful for the transition.
